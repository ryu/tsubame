# 0006. フィード購読時の URL 競合は既存レコードで購読し直す

- 状態: 採用
- 記録日: 2026-11-21（元: `FeedsController` / `feeds_controller_test.rb` のコメント）

## 背景

`Feed` はユーザー間で共有され、`url` に一意制約がある。`Feed.resolve` は、オートディスカバリのあいだ（ネットワーク I/O を含む）は未保存の `Feed` を返す。そのため、その間に別のユーザーやリクエストが同じ URL を登録するとこちらの保存が失敗する。

## 決定

- バリデーションエラーで保存できなかったとき、同じ URL の `Feed` がすでにあれば、そちらを購読する
- 同時挿入で `ActiveRecord::RecordNotUnique` が発生したときは、先に保存された側のレコードを引き直して購読する
- 候補が複数見つかり選択画面を出すときは、422 で返す。Turbo Drive はフォーム送信への 200 応答を「リダイレクトが必要」として黙って無視するため、422 にしないと選択画面が描画されない
