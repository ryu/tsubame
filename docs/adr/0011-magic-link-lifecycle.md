# 0011. マジックリンクの消費タイミングと有効期限

- 状態: 採用
- 記録日: 2026-11-21（元: `MagicLinksController` / `magic_link_test.rb` のコメント）

## 決定

- `GET /magic_links/:token`（show）では確認ページを表示するだけで、トークンは消費しない。消費するのは、ユーザーがボタンを押したときの POST だけにする。メールスキャナがリンクを先読みしても、トークンが使われてしまわないようにするため
- リンクを再送するたびに、直前のリンクはまだ有効でも破棄する。有効なトークンが増えていかないようにするため
- 有効期限の判定は Range で書いているが、Range では始端を排他にできない。そのため、期限ちょうどのリンクはまだ有効として扱う
